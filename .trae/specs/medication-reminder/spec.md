# 日常用药提醒应用规范

## 为什么需要
帮助用户管理日常用药，避免漏服或误服药物。通过智能提醒和用药记录功能，提升用药依从性，保障用药安全。

## 什么变化
- 创建移动优先的用药提醒应用
- 支持从药品说明、医嘱或口头描述生成提醒
- 每日用药记录功能
- 本地数据持久化存储

## 影响范围
- 受影响的功能：药品管理、提醒生成、用药记录
- 核心代码：前端应用（HTML/CSS/JavaScript）

## 新增需求

### 需求：药品管理
系统应允许用户添加和管理药品信息

#### 场景：添加新药品
- **当** 用户点击"添加药品"按钮
- **然后** 展示药品添加表单
- **并且** 用户输入：药品名称、剂量、服用时间、服用方式、注意事项
- **然后** 系统保存药品信息并显示在药品列表中

#### 场景：编辑药品
- **当** 用户点击已有药品
- **然后** 展示药品编辑表单
- **然后** 用户修改信息并保存
- **并且** 系统更新药品列表

#### 场景：删除药品
- **当** 用户在药品详情页点击删除
- **然后** 系统显示确认对话框
- **然后** 用户确认后，系统删除该药品及其相关提醒

### 需求：用药提醒生成
系统应根据药品信息和用户描述智能生成用药提醒

#### 场景：从描述生成提醒
- **当** 用户输入药品描述或医嘱内容
- **然后** 系统解析文本提取关键信息（药品名、剂量、频次、时间）
- **然后** 系统自动创建对应的用药提醒
- **并且** 提醒包含：时间、药品名、剂量、服用方式

#### 场景：手动创建提醒
- **当** 用户选择具体时间和频次
- **然后** 系统创建提醒任务
- **然后** 到达提醒时间时，系统通过浏览器通知提醒用户

### 需求：每日用药记录
系统应记录用户的实际用药情况

#### 场景：记录用药
- **当** 提醒触发或用户主动打开应用
- **然后** 用户可以标记"已服用"或"跳过"
- **然后** 系统记录该次用药状态和时间戳
- **并且** 显示今日用药进度

#### 场景：查看历史记录
- **当** 用户点击"用药记录"标签
- **然后** 系统展示近期的用药记录列表
- **然后** 每条记录显示：药品名、时间、状态
- **并且** 支持按日期筛选

### 需求：提醒通知
系统应在规定时间向用户发送用药提醒

#### 场景：浏览器通知
- **当** 到达设定的用药时间
- **然后** 系统发送浏览器桌面通知
- **然后** 通知内容包含：药品名、剂量、服用方式
- **并且** 点击通知可打开应用记录用药

#### 场景：通知权限
- **当** 用户首次添加药品时
- **然后** 系统请求通知权限
- **然后** 如果用户拒绝，系统显示应用内提醒替代方案

## 数据模型

### 药品 (Medication)
```javascript
{
  id: string,
  name: string,              // 药品名称
  dosage: string,            // 剂量（如：1片、5ml）
  frequency: string,         // 频次（如：每日3次、每8小时1次）
  times: string[],           // 具体服用时间数组 ['08:00', '14:00', '20:00']
  method: string,            // 服用方式（如：饭后、饭前、空腹）
  notes: string,             // 注意事项
  createdAt: timestamp,
  updatedAt: timestamp
}
```

### 用药记录 (MedicationLog)
```javascript
{
  id: string,
  medicationId: string,      // 关联的药品ID
  scheduledTime: timestamp,   // 计划服用时间
  actualTime: timestamp|null, // 实际服用时间
  status: 'pending'|'taken'|'skipped',
  notes: string,             // 当日备注
  createdAt: timestamp
}
```

### 提醒 (Reminder)
```javascript
{
  id: string,
  medicationId: string,
  time: string,              // 时间 'HH:mm'
  enabled: boolean,
  days: number[],            // 0-6 表示周日到周六
  createdAt: timestamp
}
```

## 技术实现

### 存储方案
- 使用 LocalStorage 存储所有数据
- 数据结构：medications[], logs[], reminders[]
- 定期导出/导入功能

### 提醒机制
- 使用 setTimeout 和 setInterval 检查提醒时间
- 配合 Notification API 发送浏览器通知
- 应用打开时检查是否有待提醒的药品

### 响应式设计
- 移动端优先，适配手机屏幕
- 触摸友好的大按钮和间距
- 支持横屏和竖屏模式

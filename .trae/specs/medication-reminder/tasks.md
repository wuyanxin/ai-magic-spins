## 技术选型
- **前端框架**：纯HTML5 + CSS3 + JavaScript（无框架依赖）
- **数据存储**：LocalStorage
- **通知方式**：Web Notifications API
- **构建工具**：无（单文件应用）
- **图标库**：内联SVG图标
